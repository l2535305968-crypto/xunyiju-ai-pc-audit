# 寻祎居 · 算力底牌侧写（你是谁 · AI 眼里的这台电脑）
**XunyiJu · AI PC Capability Portrait (Bilingual: 简体中文 / English)**

一套面向 Windows 用户的**零门槛本地 AI 算力与开发环境体检工具**。不需要装任何依赖、不联网上传、不修改电脑配置。运行后支持选择 **简体中文** 或 **English**，10 秒内自动生成一张**「AI 模型眼里的你」**口语化侧写网页，把冷冰冰的硬件参数和环境变量翻译成大白话。

---

## 小白怎么用？（三步搞定 / Quick Start）

1. 下载本仓库（或右侧 Releases 里的 `寻祎居_电脑AI算力底牌侧写工具.zip` 压缩包），**解压到电脑任意文件夹**。
2. 双击运行 **`一键检测电脑AI能力.bat`**（或直接双击 `AI_PC_Environment_Audit.ps1`）。
   - 程序会自动优先调用 **PowerShell 7 (`pwsh.exe`)**，若未安装则自动回退至系统自带的 Windows PowerShell 5.1。
3. 在弹出的终端里选择语言（输入 `1` 或直接回车选 **简体中文**，输入 `2` 选 **English**），等待约 5~10 秒，浏览器会自动弹出你的专属侧写页面（保存在 `AI_PC_Audit_Result/index.html`）。
   - 生成的网页右上角也带有 **`简体中文 | English`** 实时切换按钮，打开后随时可以一键切换双语界面。

## 它能帮你看清什么？

页面采用**左 70% / 右 30% 非对称双栏**设计：

### 1. 左栏主角：「AI 模型眼里的你」7 段大白话侧写
不再罗列看不懂的硬件表，而是直接告诉你：
- **这台电脑是什么底子**：整机型号、系统版本、哪块硬盘最空、最适合放几十 GB 的大模型。
- **哪儿在卡你脖子**（🔴 红点标注）：比如「8GB 显存配 16GB 内存跑大视频模型不够借」「默认 Python 装成了不能调显卡的 CPU 版 PyTorch」。
- **硬件处于什么档位**（⚪ 白字事实 + 🟢 绿虚线推论）：能顺畅跑 7B/8B 聊天模型、SDXL 画图，还是能跑 Wan 2.2 5B、FramePack 这类低显存视频模型。
- **待机姿态干不干净**：后台是不是被浏览器硬件加速或模拟器偷走了近 2GB 显存，显卡功耗是不是被锁在了保守档位。
- **平时爱折腾什么**：自动盘点机子里的 Python、Conda 虚拟环境、Node.js、Rust、Docker、FFmpeg、VS Code 状态。
- **跟上回比有什么变化**：每次重跑都会自动对比上次快照，标出可用显存变化、PowerShell 终端版本升级和新修好的工具链。

> 💡 **交互提示**：把鼠标放到正文里任何带 **红点**、**白字下划线** 或 **绿虚线** 的词上（或直接点按它），会立刻弹出这句结论背后的底层实测字段和判断依据。

### 2. 右栏并排：「破绽与卡点诊断」
- **醒目数字 + 档位徽章**：一眼看清有几处地方会卡住你。
- **「🔥 先改这几项」置顶卡**：按性价比给出最该先动手的修复项（附带可直接复制的修复命令）。
- **逐项大白话清单**：红灯（立刻卡脖子）、黄灯（跑大模型受限）、绿灯（健康就绪）分门别类。

### 3. 左栏下方：低调双列技术密表
- 完整的底层探测值退居左栏下方，支持关键词实时搜索（如搜 `cuda`、`显存`、`conda`），既不抢首屏总结的风头，又方便老手查具体版本号。

## 生成的文件都在哪？

运行完成后，目录下会多出一个 `AI_PC_Audit_Result` 文件夹：
- `index.html`：中英双语交互式可视化侧写网页（可随时双击打开）。
- `AI_PC_Report.txt`：纯文本完整检测报告（适合发给朋友或 AI 助手帮你排查环境）。
- `AI_PC_Snapshot.json`：结构化硬件与环境快照（用于和下一次扫描自动对比变化）。

> ⚠️ **隐私提醒**：本工具完全在本地运行，不会向任何服务器发送数据。但如果你要把生成的 `AI_PC_Report.txt` 或截图发给别人看，建议先扫一眼里面的 Conda 环境名或本地文件夹名字是否包含个人隐私。
